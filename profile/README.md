# NanoScrape

**Pay-per-result web scrapers for the Apify Store.**

NanoScrape publishes HTTP-only, Go-based web scrapers on the Apify Store. They cover job boards, business directories, marketplaces, social media and e-commerce. You pay per result, from $1 per 1,000 results. There is no monthly fee and no setup.
